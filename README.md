# E-Commerce DevOps CI/CD Pipeline

## Project Overview
This project demonstrates an end-to-end DevOps CI/CD pipeline for a multi-service E-Commerce application using Docker, Jenkins, Nginx, Linux, and AWS fundamentals.

## Tech Stack
- Linux
- Docker
- Docker Compose
- Jenkins
- Nginx
- Node.js
- AWS Fundamentals

## Features
- Multi-container application setup
- CI/CD pipeline automation
- Docker container orchestration
- Frontend and backend separation
- Deployment workflow automation
- Container troubleshooting and debugging

## Project Architecture
Frontend → Nginx → Backend

## CI/CD Workflow
Code Push → Jenkins Build → Docker Build → Deployment
